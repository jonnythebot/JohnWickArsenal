> **Current development workflow:** Open `UnityProject` in Unity 2022.3.20f1 through Unity Hub. See the [local build guide](BUILD_SYSTEM.md) for Android export, license setup, and the remaining Nomad SDK work.

## Installation

### Requirements
- Blade & Sorcery Nomad (Quest)
- BSMG Mod Loader or Mod.io

### Manual Install (BSMG)
1. Download latest release
2. Extract to `/sdcard/Mods/JohnWickArsenal/` on Quest
3. Enable in Mods menu

### Mod.io
1. Subscribe to "John Wick Arsenal" in-game
2. Restart game

## Controls

### Pistols/Rifles
- **Trigger**: Fire
- **Grip (off-hand)**: Slide release / Bolt release
- **Touchpad/Joystick Up**: Tactical reload
- **Touchpad/Joystick Down**: Empty reload
- **Grip + Trigger**: Inspect weapon

### Shotguns
- **Trigger**: Fire
- **Pump Action**: Rack slide (Benelli) / Pump (KSG)
- **Off-hand Grip + Joystick**: Load shell
- **KSG Only - Touchpad Left/Right**: Switch magazine tube

### Revolver (Remington 1875)
- **Trigger**: Fire (cocks hammer automatically)
- **Grip + Trigger**: Manual hammer cock
- **Touchpad Up**: Open loading gate
- **Touchpad Down**: Ejector rod
- **Off-hand Touch**: Load single round

### Throwables
- **Trigger**: Throw
- **Grip**: Retrieve (when stuck in target)
- **Touchpad**: Quick throw (no aim)
